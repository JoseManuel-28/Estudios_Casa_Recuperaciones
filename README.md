## 🚀 Contenido del Repositorio

El proyecto está organizado en diferentes clases, cada una resolviendo un problema específico de lógica de programación:

*   **Actividad 1:** Operaciones aritméticas básicas (Suma, Resta, Multiplicación y División).
*   **Actividad 3:** Conversor de Euros a Pesetas.
*   **Actividad 5:** Conversor de Pesetas a Euros con gestión de decimales.
*   **Actividad 7:** Cálculo del área de un cuadrado.
*   **Horario:** Sistema de consulta de asignaturas mediante condicionales `if-else` y `switch`.

---

## 🛠️ Tecnologías y Conceptos Aplicados

Para la realización de estas actividades se han aplicado los siguientes conceptos fundamentales de Java:

*   **Programación Orientada a Objetos (POO):** Uso de clases, constructores y métodos.
*   **Estructuras de Control:** Condicionales `if`, `else if` y `switch`.
*   **Entrada de Datos:** Uso de la clase `Scanner` para interactuar con el usuario.
*   **Tipos de Datos:** Manejo de `int`, `double` y `String`.
*   **Operaciones Matemáticas:** Lógica de cálculo y uso de `Math` en Java.
